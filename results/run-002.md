# Run 002 — friendly voice, 11 categories, no reasoning block

Changes from run 001: three categories added to the training data
(`invalid_size`, `ambiguous_match`, `vague_request`), corpus 800 → 900, share
of examples ending in a tool call 80% → 70%, and Qwen3's empty
`<think></think>` block stripped when building the training text.

| | |
|---|---|
| Base model | `unsloth/Qwen3-4B-Instruct-2507-bnb-4bit` |
| Method | QLoRA, r=16, alpha=16, all 7 attn+MLP projections |
| Data | 900 generated dialogues (seed 42), loss on assistant turns only |
| Schedule | 3 epochs, lr 2e-4, effective batch 8, fp16 |
| Adapter | `eneskaya96/coffee-order-friendly` |

## What the changes fixed

All three targeted failures resolved. `invalid_size` went 33% → 100%: the model
no longer writes a size the menu does not list. `ambiguous_match` 50% → 100%,
`vague_request` 60% → 100%. The empty reasoning block is gone from every
generation, and with it the corrupted output from run 001 that opened
`<tool_call>` and closed `</think>`.

## What the changes broke

`negation` fell from 75% to 25%, below the prompted base model's 50%, with
`format_ok` at 50% — in half those examples the tuned model emitted no tool call
at all. `messy_phrasing` fell from 100% to 67%.

The cause is the same edit that fixed the rest. Adding three ask-instead-of-order
categories and dropping the tool-call share from 80% to 70% moved the model
toward hesitation, and it now hesitates where the request is already
unambiguous:

    USER : americano. large. thats it
    TUNED: One large americano — anything else?

The customer said "that's it". Product, size, and completion are all stated, and
the model still asks. Fixing over-eagerness produced under-eagerness; the
training data has no examples that mark a request as complete and terse, nor any
where a negation ("no syrup", "not oat milk") is simply honoured without a
follow-up question.

## Next

Rebalance rather than revert: keep the three new categories, add examples where
the customer closes the order explicitly and where a negation is acted on
directly. The tool-call share needs to land between 70% and 80% rather than at
either end.
